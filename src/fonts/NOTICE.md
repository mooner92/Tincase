# 페이퍼로지 (Paperlogy)

- 버전 1.000 · 패밀리 `Paperlogy` / `페이퍼로지`
- 저장소에는 앱이 실제로 쓰는 **4종만** woff2로 변환해 둔다 (400·500·600·700).
  원본은 TTF 9종 약 6MB, 변환 후 4종 640KB.

## 왜 4종만인가

안 쓰는 굵기는 브라우저가 한 번도 내려받지 않으면서 저장소만 불린다.
굵기를 새로 쓰게 되면 원본 TTF에서 다시 변환해 추가한다:

```py
from fontTools.ttLib import TTFont
f = TTFont('Paperlogy-3Light.ttf'); f.flavor = 'woff2'
f.save('Paperlogy-300.woff2')
```

## 글자 커버리지 (실측)

- 한글 음절 **11,172자 전부** — 사용자가 무엇을 적어도 대체 글꼴로 새지 않는다
- 영문 대소문자·숫자 · 자주 쓰는 기호(`·` `—` `→` `←` `●` `○` `«` `»` `×` `…`) 포함
- **없는 것**: `✓` `▾` `★` `⚠` 등 일부 기호 → 그 글자만 시스템 글꼴로 그려진다

## 라이선스

**오픈소스 · 재배포와 웹 임베딩 가능** (2026-08-18 사용자 확인).
그래서 woff2 파일을 이 저장소에 그대로 둔다 — public 저장소지만 문제되지 않는다.

여기 적어두는 이유: 저장소에 폰트 바이너리가 있으면 나중에 누군가
"이거 올려도 되나?"를 다시 묻게 된다. 한 번 확인한 것은 기록으로 남긴다.

원본 TTF 9종은 저장소에 넣지 않았다. 변환된 4종으로 충분하고,
다른 굵기가 필요하면 위 명령으로 원본에서 다시 뽑는다.
