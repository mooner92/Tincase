# ADR-0003. SQLite + Prisma

- 상태: **채택** (2026-08-13)
- 관련: [S-01](../spec/01-domain-model.md), [S-09](../spec/09-deployment-ops.md)

## 맥락

8명이 주 1회 파일을 올린다. 예상 규모는 **연 830행, 100 MB**.

## 결정

**SQLite (WAL 모드) + Prisma.** 원 스펙 §8 제안 그대로 유지한다.

## 근거

1. **쓰기가 사실상 없다** — 주당 8~16 write. 동시성 문제가 발생할 여지가 없다
2. **운영 부담 0** — 별도 서버·백업 도구·접속 관리 불필요
3. **백업이 파일 복사** — `sqlite3 .backup` 한 줄 (OPS-07)
4. **Prisma로 타입 안전 + 마이그레이션 이력** 확보
5. 10년 운영해도 1 GB 미만

Postgres는 이 규모에서 **얻는 것 없이 운영 대상만 하나 늘린다.**

## 주의사항

| ID | 내용 |
|---|---|
| — | WAL 모드 활성화 (`PRAGMA journal_mode=WAL`) |
| — | 백업은 반드시 `.backup`. `cp` 금지 (WAL 때문) |
| — | 볼륨은 **로컬 디스크**. NFS 위 SQLite는 잠금이 깨진다 |
| — | 쓰기 트랜잭션은 짧게. 파일 I/O를 트랜잭션 안에 넣지 않는다 (ST-10) |

## 되돌리는 조건

동시 사용자가 수십 명으로 늘거나 다른 서비스가 같은 DB를 공유해야 하면 Postgres로.
Prisma를 쓰므로 전환 비용은 스키마 provider 변경 + 데이터 이관 수준이다.
