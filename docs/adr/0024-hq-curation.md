# ADR-0024. 본부 다듬기 — 본부본에서 **빼기만** 하고, 본부 취합 규칙은 **미리 고르기**다

상태: 채택 · 2026-10-22 · 관련: [TACP-21·23](../../TACP.md) (v1.19 개정) · [ADR-0015](0015-approval-is-handoff.md) · [ADR-0022](0022-one-person-many-desks.md) · [14 연구 본부 §20](../spec/14-research-hq.md)

## 맥락

국토환경연구본부 본부 담당이 취합 규칙을 보내왔다(2026-10-22, 운영자 전달). 요지는 「각 실에서 보내온 일정을 **기관평가에 쓸 수 있게
중요 안건 위주로 분량을 덜어서** 주요 안건만 보고한다」 — 주간 1장 · 월간 2장, 연구원 사업의 보고회는 목록에 적지 않고 자문회의 건수로만,
특이사항은 이번 주 실적 중 대표성 있는 것만, 애매하면 기본은 뺀다.

지금 Tincase의 본부본은 산하 실 병합본을 **그대로 이어 붙인다**(RH-84). 본부 담당이 덜어 낼 길이 없다 — 본부본을 받아 한글에서 지우고
올리는 길도 3단계에는 없다(본부본은 자동 조립이고 본부장은 그 판을 승인한다, TACP-23). §16의 틈 G2(본부 담당의 손질)와 G5(1쪽 맞추기)가 이것이다.

9월 4주 · 10월 3주 국토 제출본과 대조하면 규칙은 대체로 지켜지지만 어긋나는 곳도 있다(특이사항에 다음 주 일이 들어감 · 기본 과제의
정책실무협의회가 목록에 있음). 규칙은 기계가 끝까지 정할 수 있는 것이 아니고, 본부 담당 자신도 「애매한 건은 담당자가 검토」라고 한다.

## 결정

### 1. 빼기만 한다 — 글은 고치지 않는다

다듬기는 **본부본에 넣을 항목을 고르는 것**(체크 · 빼기와 다시 넣기)과 **자문회의 표 값 고치기** 둘뿐이다. 문구·날짜·순서를 고치지 않는다.

- 본부본은 여전히 「받은 사본 + 순서 + 양식」의 함수이고, 다듬기는 거기에 붙는 **결정 목록**이다 — 실이 다시 내면 새 사본으로 다시 만들어지고,
  같은 항목에는 같은 결정이 붙는다(항목 열쇠 = 실 · 과제 · 내용 · 일자로 만든 값)
- 글을 고치려면 실이 고친다(실 담당의 병합본 고치기 · 담당의 제출물 고치기). 본부에서 글을 고치면 실 사본과 본부본이 갈라지고, 실이 다시 낼 때
  본부의 손질이 사라지거나 덮어써야 한다 — 그 문제를 이번에 들이지 않는다(G2의 나머지는 쓰는 본부가 생기면)

### 2. 본부 취합 규칙은 미리 고르기다 — 저장은 사람이 다르게 정한 것만

본부마다 규칙이 있으면(코드 — `curateRulesOf`, 지금은 국토환경 하나) 규칙이 항목마다 넣음/뺌과 이유를 낸다. 저장하는 것은
**사람이 규칙과 다르게 정한 것뿐**이다. 그래서

- 아무도 손대지 않아도 국토 본부본은 규칙대로 덜어진 판이다(본부 담당의 현행이 그렇다 — 「기본은 제외」)
- 규칙이 고쳐지면 사람이 손대지 않은 항목은 새 규칙을 따른다. 규칙 판(`version`)은 본부본 입력 열쇠에 들어간다
- 규칙이 없는 본부는 다듬기 전과 **같은 본부본**이다 — 열쇠도 같다(배포만으로 본부본이 다시 만들어져 승인이 풀리지 않게)

규칙을 화면에서 고치게 하지 않는다. 본부가 다섯이고 규칙은 문장으로 오며 해석이 필요하다(「연구원 사업」이 어느 유형인가). 바뀌면 스펙과 코드를 같이 고친다.

### 3. 권한은 본부 순서와 같은 칸 — 저장하면 본부본을 다시 만들고 승인은 다시

본부 소속 lead·head와 지정된 본부 담당(ADR-0022 D2) — `requireHqManager`. 저장은 입력 열쇠를 바꾸므로 그 자리에서 본부본이 다시 만들어지고,
본부장이 이미 승인했으면 새 판을 다시 승인해야 올라간다(순서를 바꿀 때와 같다, RU-55a). 감사 `hq_curate`.

### 4. 분량은 보여 주기만 한다

다듬기 화면 맨 위에 「약 0.9쪽 · 주간 1쪽 이내」(§6 안 A). 줄 수 어림이라 한글의 실제 줄바꿈과 조금 다르다 — 막지 않는다. 계수는 국토 양식으로
만든 본부본을 그려 잰 값이다.

## 채택하지 않은 것

- **규칙만 자동으로**(화면 없이): 애매한 것을 사람이 볼 수 없다. 규칙이 틀리면 본부장이 받은 판에서야 안다
- **본부본 직접 고치기**(실형 병합본 고치기처럼): 1의 이유 — 실이 다시 내면 갈라진다. 현행 국토 담당이 하는 일의 대부분은 빼기다
- **실에서 덜어 오기**(실 담당이 규칙대로 골라 보냄): 실 셋이 같은 규칙을 따로 지켜야 하고, 분량은 본부를 합쳐야 보인다
